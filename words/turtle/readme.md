# 无我海龟汤（设计说明，含剧透）

和 `words/corridor`（无我回廊）是同一个主题（无我），但汤底更「meta」——全部规则都针对选手**自己的发言**，没有七号门、钟、走廊这些物件：
选手的任务就是**猜出汤底**，并且尽可能活下去；环境是「汤主」，知道汤底，只用「是 / 不是 / 无关」回答。

## 汤底（圣言）

| 编号 | 内容 |
|---|---|
| K1 禁字之规 | 说出「我」字的选手立刻死亡（含「我们」「自我」，含遗言和宣告）。**只在心里想（thought）不算。** |
| K2 同场之约 | 两位选手同场满 5 轮，期间没人主动赴死，则两人同死 |
| K3 名讳之禁 | 说出自己名字的选手立刻死亡（包括「某某想问……」这种第三人称自称；别人的名字不算） |
| K4 世界的本质 | 这是囚禁同胞的循环牢笼，宣告全部真相才能放大家自由 |
| K5 共同的原则 | 不容许「自我」（K1、K2、K3 的共同原因：不能说我、不能说自己的名字、不能两个自我共存） |

## 和 corridor 的区别

|  | corridor（无我回廊） | turtle（无我海龟汤） |
|---|---|---|
| 环境 | 叙述者，**不知道**规则，只描写场景 | 汤主，**知道**汤底，只回答是非题 |
| 场景 | 大堂、镜子、走廊、客房、告示牌、钟、黑门 | 什么都没有，只有汤主的声音 |
| 线索来源 | 探索 + 告示牌 + 回声墙 | 提问 + 前人最后的话（回声） |
| 难点 | 发现「我」字是禁字 | 提问时不能带「我」，也不能念自己的名字（用第三人称自称同样会死）；要问出禁字是哪一个，而汤主不会直接告诉你 |

## 汤主的信息边界

- 汤主**不会**说出汤底原文，也**不会**说出禁字是哪个字。选手只能问「是不是第一人称自称？」这类问题，再自己推出来。
  直接问「是『我』吗？」会因为问句里出现了那个字而被处决。
- 「名讳之禁」是专门堵「顾迟想先问……」这种第三人称自称的：躲开「我」字最自然的办法，恰恰是第二条要命的规则。
- 同一个问题答案必须一致；拿不准时用「无关」或「是，但不全」。
- 开放式提问（为什么 / 是什么）一律让选手换成是非题，这样每个答案都只给出一点点信息。

## 想法和发言

选手每次输出 `thought`（脑子里想的）和 `content`（说出口的）。裁判、汤主、同伴只会看到 `content`；
`thought` 只给观众看（前端画成虚线的「心想」气泡），也不会被惩罚。

## 调难度

- 想简单：让汤主在被问到「有没有不能说的字」时补一句「是一个字」；或者把「新选手入场时念前人的话」的条数加大（`game.py` 的 `ECHO_MAX`）。
- 想难：去掉汤主对「是，但不全」的使用，只留「是 / 不是 / 无关」；或者不念前人最后的话（`world.json` 里 `echo_wall` 设为 `false`）。
