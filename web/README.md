# web：AI 饥饿秀前端（8-bit 像素风）

纯静态页面，不需要构建，双击 `index.html` 就能打开。

```
web/
├─ index.html          页面骨架：演出区 + 2×2 按钮 + 对话区
├─ css/style.css       像素风样式（调色板、像素边框、响应式）
├─ js/sprites.js       像素图（文本位图 → SVG）：头像、按钮图标
├─ js/app.js           对话气泡（打字机）、占位按钮、演出区占位画面
└─ assets/fonts/       Fusion Pixel 12px 简体像素字体（OFL 协议，见 OFL.txt）
```

## 常用操作
- **新增一条对话**：`HungerUI.addMessage('a', '台词')`，说话者 id 见 `app.js` 的 `SPEAKERS`（`env` 环境 / `a` / `b`）。
- **新增选手**：在 `SPEAKERS` 加一项（`side` 决定头像在左还是右）→ 在 `sprites.js` 画一个头像 → 在 `style.css` 加 `.sp-xxx` 配色。
- **改图标 / 头像**：直接改 `sprites.js` 里的字符画（12×12，每个字符一个像素，`.` 透明）。
- **演出区**：`#stage-canvas` 铺满演出区，逻辑分辨率由 `fitStage()` 按容器尺寸算出（整数倍放大、保持像素锐利，窗口缩放时自动重算）。`drawStage` 是占位画面，之后换成 sprite 演出。
- **调试参数**：`?instant` 跳过打字机效果和入场动画；`?empty` 不放演示对话。

## 适配
- 手机竖屏：单列，宽度跟随屏幕（已测 320 / 360 / 390px）。
- 手机横屏 / 矮窗口（高度 ≤ 520px）：自动切成左右分栏（左：演出区 + 按钮，右：对话）。
- 电脑（≥ 900×600）：竖条放宽到 1000px；大屏显示器（≥ 1600×800）放宽到 1200px。按钮、图标、头像按整数倍放大，选手消息靠右、环境消息靠左，气泡不会被拉得太长。
- 平板：居中的 480px 竖条，两侧是棋盘格底纹。
- 已处理刘海屏安全区（`env(safe-area-inset-*)`）和手机双击缩放。
- 图标和头像是 12 格位图，尺寸必须是 12 的整数倍（36 / 48 / 60 / 72px），否则像素会发糊。新增断点时注意这一点（见 `style.css` 里的 `--icon`、`--av`）。
